# 奶蛙大乱斗：98 风格规则与操作

本作参考《拳皇 ’98》ADVANCED 的四键攻击、步法、防御、翻滚与能量系统，使用原创奶蛙角色、招式、伤害和时间参数。它不是原作模拟器，也不承诺逐帧复刻。

## 操作

| 动作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 移动 / 跳跃 / 蹲下 | A、D / W / S | 左右 / 上 / 下方向键 |
| 轻拳 A / 轻脚 B | J / U | 1 / 4 |
| 重拳 C / 重脚 D | K / I | 2 / 5 |
| 防御辅助键 | L | 3 |
| 翻滚 / 近身投技 | O / H | 0 / 6 |
| MAX 爆气 / 超必杀 | N / 空格 | 9 / 回车 |

玩家 2 的数字键同时支持主键盘与小键盘。手机使用游戏下方方向与动作按钮，可以同时按住多个按钮。

方向均相对于对手：按后方向可边退边防，蹲下加后方向为蹲防；辅助防御键等效于防御意图。站防挡中段与跳攻，蹲防挡中段与低段；普通攻击被防住时不削血，指令技与超必杀有少量削血，持续压力能破防。

连点前方向跑动，连点后方向后撤。跳跃在 0.12 秒内松开会变为小跳，按住为普通跳；蹲下或松开蹲键后 0.16 秒内起跳为高跳。跑动起跳保留更快横向速度，轻点可作快速小跳。空中四键攻击会使用空中动作与判定；释放方向或出招不会抹掉起跳惯性。越过对手时保留起跳朝向，落地后转向。

## 指令与特殊操作

| 指令（面向右） | 实际效果 |
| --- | --- |
| ↓↘→ + 任一攻击（236） | 角色指令技；狂笑奶蛙发射笑气波，其他奶蛙向前冲击 |
| ↓↙← + 任一攻击（214） | 近身指令技 |
| →↓↘ + 任一攻击（623） | 上勾攻击，可击倒 |
| ↓↘→↓↘→ + 任一攻击（236236） | 超必杀；也可使用超必杀辅助键 |
| A+B | 翻滚；按后方向为向后翻滚 |
| C+D | 吹飞攻击；空中也可使用 |
| A+B+C | MAX 爆气 |

四种攻击键均可完成上述搓招，轻重会影响指令技。普通必杀不消耗能量豆；普通重拳不发射远程波。翻滚中段可躲打击，起手和收招有破绽，仍可被投技抓住。投技的抓取起手有 0.15 秒拆投窗口，按投技键可拆；普通投技不能抓处于受击、防御硬直或起身保护中的目标。

防御硬直中 A+B 可消耗一豆取消成翻滚，C+D 可消耗一豆反击。可受身的腾空击倒，在落地前 0.25 秒内输入翻滚可受身；投技和超必杀造成的击倒不提供此受身。四种普通攻击命中或被防住后，可在有效攻击结束后的短窗口接指令技或超必杀；投技和吹飞不能这样取消。只有在对方仍处于受击硬直时续上伤害才计作连段。

## 能量与模式

能量来自命中、被防、受击及空招，不会随时间自动增加。空放普通指令技也能攒气。最多存三豆，存满后不暗藏第四豆；超必杀消耗一豆。MAX 爆气消耗一豆，持续 8 秒并增强伤害；MAX 中超必杀再消耗一豆，增强超必杀后结束 MAX。

经典模式挑战六位对手，无限模式持续追加对手；每胜一擂重新满血。双人模式三局两胜。竞技回合限时 99 秒，到时按剩余生命比例判胜，平局重赛。练习室的生命和能量无限、计时不递减，可切换木桩站防/蹲防并查看判定框，伤害和连击仍会记录；练习成绩不计最高分。

暂停、换游戏和新回合会清除按住状态、缓冲攻击及双击历史。恢复后第一次按前方向不会误触跑动。

## 本项目的输入窗口

| 项目 | 当前数值 |
| --- | --- |
| 双击方向 | 0.25 秒 |
| 单次指令 / 双下前超必杀 | 0.50 / 0.85 秒 |
| 指令相邻有效步骤间隔 | 最多 0.22 秒 |
| 最后方向后接攻击 | 最多 0.16 秒 |
| 攻击缓冲有效期 | 0.14 秒 |
| 同帧按键合并 | 1/120 秒 |

先长按起始方向（例如蹲住后搓 236）有效，长时间停在中间步骤则失效。同一仿真时刻的方向事件取最终状态；攻击稍后统一判定，降低键盘或触控事件顺序的影响。转向会清除旧方向序列，识别出的指令只消费一次。这些窗口是为网页键盘与触控设计的容错参数，不是 SNK 公布的原版帧表。

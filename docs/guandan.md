# 奶蛙掼蛋

四人两队的本地人机对战：你是 0 号，右手 1 号、对家 2 号、左手 3 号。0 与 2 组队，1 与 3 组队；轮次按这个顺序跳过已出完者。两副标准扑克牌共 108 张，每人 27 张。第一副从 2 开始，由玩家先出。

## 牌型与比较

| 牌型 | 张数与限制 |
| --- | --- |
| 单张、对子、三张 | 同点数；对子可为两小王或两大王 |
| 三带对 | 三张同点数加另一点数的一对，只比三张部分 |
| 顺子 | 恰好 5 个连续点数 |
| 连对 | 恰好 3 个连续对子，共 6 张 |
| 钢板 | 恰好 2 个连续三张，共 6 张 |
| 同点炸弹 | 4 至 10 张；先比张数，再比点数 |
| 同花顺 | 同花色的 5 张顺子 |
| 四王炸 | 两小王加两大王 |

普通牌只能由同牌型、同张数且更大的一手压过。炸弹层级为：四王炸 > 六张及以上同点炸 > 同花顺 > 五张炸 > 四张炸 > 普通牌。同点炸弹张数相同时比点数；同花顺比序列高点，花色不分大小。

单张与同点组的牌力为大王、小王、当前级牌、A 到 2。连续牌型按自然点数，级牌仍占原位置；A 可以低用或高用，允许 A2345、AA2233、AAA222，不允许 QKA23、KKAA22。

两张红桃级牌是百搭，可替非王的点数和花色；单独出一张时仍是级牌。百搭不能凑王对或四王炸。两百搭可以声明非王对子。一个选牌集合若有多个合法解释，下方下拉框列出能够领出或压过当前牌的解释；实际提交沿用玩家选择，提示也会显示所用解释。

## 轮次与升级

领出者必须出牌。其他玩家可以接牌或不要；出一手新牌后重新计算各家是否放弃。其余仍有牌者都不要时，由最大牌玩家再次领出；若其已出完，则由仍有牌的对家接风。必要时顺位寻找仍有牌的玩家。

出完顺序决定头游、二游、三游、末游。一队包揽前两名时立即双下结算，未出完的两家共同双下，不虚构出完顺序。否则第三人出完即确定末游。头游方获胜，按对家二游、三游、末游升 3、2、1 级；升级封顶 A。必须实际打 A 并获得头游且对家非末游才过 A。

单局模式一副结束即结算。连续升级记录两队各自级数，下一副打上副胜方的新级数；过 A 后胜方回到 2，记录过 A 次数，继续牌局。玩家主动点下一副或结束本次累计，不设局数终点。重新开始、刷新或切游戏会重新开桌，不恢复未结束牌局。

## 自动贡还

后续每副发完 27 张后进行贡还：

- 单下由末游向头游进贡手中最大非百搭牌，级牌仍按牌力比较。
- 双下两家各进贡一张，较大牌给头游，另一张给二游；同点时头游下家优先。
- 受贡者自动还最小的非级牌且点数不超过 10 的牌；无此牌时还最小非百搭牌。
- 单下进贡者持有两张大王，或双下两人合计持有两张大王，可以抗贡，由头游领出。
- 未抗贡时单下进贡者领出；双下较大贡牌者领出，同点按头游下家优先。交换后各家仍各有 27 张。

贡还过程与抗贡原因显示在手牌区域下方。自动还牌、第一副玩家领出以及过 A 后重开等级，是适合本作连续人机游玩的明确约定。

## AI、反馈与积分

AI 使用自身手牌、桌面牌、公开剩牌数与队伍关系。优先直接出完；队友占优时可以放行，对手只剩一两张时优先拦截。一般保留炸弹、百搭并减少拆组；合法候选由牌型模板生成，不枚举全部手牌子集。提示可循环合法选择，托管使用同一决策策略。

你每打出一张得 5 分；本方获胜加 500，自己头游加 200、二游加 100。单局最多 835 分，连续升级累计，未完成手牌不会补分。提示和托管属于允许玩法。两个分榜与其他游戏分开，排行榜仍采用社区成绩校验。

对方赢牌会播放奶蛙原有的捧腹大笑动画与笑声音频。庆祝阶段保留 2.4 秒再显示结算；自动暂停同时冻结 AI、计时和动画。静音、重开或切游戏沿用全站音效停止机制。

## 规则参考与验证

牌型、比较、百搭、接风与贡还参考 [南京体育学院公布的掼蛋比赛规则](https://www.nsi.edu.cn/jgzj/75/d2/c1954a30162/page.htm) 和 [东南大学公布的两副牌掼蛋比赛规则](https://xxgk.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)。本作以本页明确列出的规则为准，赛事处罚、计时与赛事积分不纳入休闲游戏。

规则测试涵盖全部牌型、A 的两端用法、百搭替换边界、大小王限制、炸弹顺序及合法候选一致性。游戏测试通过真实合法出牌推进不同种子的完整牌局，检查牌张守恒、接风、双下、贡还、抗贡、升级、积分和胜利笑声。浏览器测试验证实际点牌、提示、暂停、托管完成牌局、下一副及手机布局。

# 奶蛙短语音来源与播放规则

游戏默认使用“梗语音”包，也可切回“经典笑声”。新增两句是真实公开视频音轨的短片段，没有用 TTS 冒充角色原声，也没有生成或克隆配音。音频在站点本地加载，游戏时不访问 B 站。

## 两个发布片段

| 文件 | 日语原句与含义 | 源视频时间段 | 成品 |

| `assets/voices/kakatte.mp3` | `かかってらっしゃい`，放马过来；“刚刚跌落水／嘎嘎滴辣虾”是中文空耳 | 00:00.000–00:01.220 | MP3，44.1 kHz，单声道，96 kbps；容器时长约 1.254 秒，15,575 字节 |
| `assets/voices/andy.mp3` | `アンディ`，安迪，角色名 | 00:01.240–00:02.910 | MP3，44.1 kHz，单声道，96 kbps；容器时长约 1.698 秒，20,904 字节 |

两句共同来自 B 站 UP“一个大的日”的[《【不知火舞】原版语音纯享版》](https://www.bilibili.com/video/BV1UiXpBrEwH/)，BV `BV1UiXpBrEwH`，分 P `cid=36993433790`，标题为发布者描述。通过公开的视频信息与播放接口取得音轨，按视频同步逐句字幕及音轨停顿定位切点。该视频是第三方上传的语音合集，不是腾讯或 SNK 的官方素材发布页，不能将它的标题视作官方认证。

处理仅包括截取、双声道合为单声道、MP3 转码、首端 5 ms 与末端 20 ms 淡入淡出；没有调音高、改播放速度、拼接新台词或语音合成。MP3 容器包含少量编码延迟，实际解码播放时长由浏览器的 AudioBuffer 决定。只将上述约三秒的短片段加入发布目录，没有分发完整视频或完整合集音轨。

原句与含义可对照[不知火舞原皮台词记录](https://www.qieyou.com/content/101466)及[技能台词空耳整理](https://www.gamersky.com/handbook/202603/2111578.shtml)。台词核对依赖这些文字记录与源视频逐句字幕；自动语音识别在本次环境未成功运行，未据此宣称人工试听确认。

## 触发与取消

`GameAudio.setVoicePack('meme' | 'classic')` 返回有效的包 ID；无效值保持原设置。`previewVoice('kakatte' | 'andy')` 返回 `Promise<boolean>`，仅在音效开启、AudioContext 已解锁运行并成功加载音频时播放。试听按钮由用户点击解锁；快速切换到另一个试听按钮会在新片段加载成功后立即替换旧试听，同一个按钮仍有短冷却。构造音频对象不会自动建立 AudioContext。

梗语音中，同一种已接受事件交替播放短句和原有笑声：

| 游戏事件 | 新短句 |
| --- | --- |
| `laugh:start`、`laugh:special`、`laugh:combo` | 刚刚跌落水 |
| `laugh`、`laugh:hurt`、`laugh:boss` | 安迪 |
| `laugh:victory` | 始终保留经典笑声 |
| `launch`、`miss` | 分别尝试前述两句；合计每 6 秒最多一句 |

轻攻击、防御、冲刺、升级的原有笑声保持。所有人声共用一个播放源和优先级、冷却管理；普通攻击笑声不会把短句截成原来的 0.32 秒，更高优先级的胜利等事件仍可替换较小事件。预加载不等待、不排队补播；加载失败时游戏事件回退到已有笑声，试听返回 `false`。整个短文件按正常速度播放，不采用笑声的断续音量包络。

暂停、切换游戏、静音调用 `stopAll()` 时立即停止声音并让未完成的试听失效；改变语音包或开始更新的试听请求同样取消旧请求。旧网络响应或解码完成不会在之后突然播放。单个短句解码时长限制为 0.1–4.5 秒，文件上限 500 KB，避免错误资源变成长段播放。

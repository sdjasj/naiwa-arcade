# 奶蛙摸鱼乐园

九款以互联网「大笑奶蛙」为主角的浏览器小游戏。角色采用黄色梨形身体、奶油大肚皮、绿眼小黑瞳的奶蛙动画图集，搭配对应笑声音频。

**在线游玩：<https://sdjasj.github.io/naiwa-arcade/>**

| 游戏 | 玩法 | 操作 |
| --- | --- | --- |
| 奶蛙飞不动 | 三档难度，每 5 管切换晴空、晚霞、星夜；碰撞挤扁后大笑 | 点击 / 触屏 / 空格 / ↑ |
| 愤怒的奶蛙 | 12 关，每关 3–5 发，选关、星级评价、建筑坍塌和反弹 | 向后拖动松手；↑↓ 角度，←→ 力度，空格发射 |
| 暴打奶蛙 | 三档难度、30 秒九宫格、金冠蛙额外加分、连击与命中率 | 点击 / 触屏 / 数字 1–9 |
| 奶蛙接不住 | 8 波挑战、3 条生命、金蛙与连击奖励，躲开炸弹 | 移动鼠标 / 触屏拖动 / 按住 ←→ 或 A、D |
| 奶蛙跳一跳 | 6 个阶段、30 座平台、落点预览、完美奖励、检查点复活 | 按住画面或空格蓄力，松开起跳 |
| 奶蛙大乱斗 | 三种角色、6 位对手、无限擂台、怒气必杀、同键盘双人三局两胜 | AD 移动、W 跳、S 蹲、J/K/L 轻拳/重拳/防御、空格大招 |
| 奶蛙幸存者 | 自动攻击、经验拾取、升级三选一、3 分钟首领战 / 无限生存 | WASD / 方向键移动、空格冲刺、1–3 选择升级 |
| 奶蛙炸弹人 | 6 关迷宫、连锁爆炸、道具成长、无限迷宫与双人对战 | WASD / 方向键移动、空格放弹 |
| 奶蛙 2048 | 12 种奶蛙形态、经典合并、撤销一步、自动续玩，2048 后可继续 | 方向键 / WASD / 滑动棋盘 / 方向按钮 |

支持快速切换游戏、暂停续玩、重开、浏览器全屏和声音开关。每款游戏独立保存最高分；飞行和打地鼠的不同难度也分别记分。切换页面或窗口失焦时自动暂停，释放蓄力与移动按键，拖动弹弓中断不消耗弹药。

弹弓关卡与最佳星级自动保存在本机，失败后直接重试当前关。2048 可选 4×4 或 6×6 棋盘，两种尺寸分别保存进度与最高分，兼容旧版 4×4 存档。使用适合手机的竖向棋盘，自动保存每次有效移动，刷新后可继续；数字与形态同时展示，合成规则清晰可辨。

八款动作游戏均可选择「经典模式 / 无限模式」，模式选择保存在本机，最高分按模式和难度分别记录。无限模式不设通关终点：

- 飞行：3 颗心，撞击后安全复位并短暂无敌，持续生成水管。
- 弹弓：持续生成工地，每关补充弹药，累计得分；不影响经典模式星级和解锁。
- 打地鼠：5 颗心，取消 30 秒倒计时；打空或漏蛙扣心，金冠蛙回复 1 心（最多 5 心）。
- 接蛙：3 条生命，波次持续生成，落速、漂移与单波数量都有上限。
- 跳跃：3 条生命，持续生成可达平台，每 5 座为新阶段，旧平台滚动回收。

生命耗尽，或弹弓弹药耗尽仍有目标时结算本局，可随时重新开始。

新增三款都提供可以同时按下的触屏方向与动作按钮，暂停、切换游戏、失焦或取消触控时会释放按键。幸存者升级时暂停敌人和计时，选择强化后继续。

大乱斗和炸弹人可在玩法中选「双人（同键盘）」。大乱斗玩家 2 使用方向键跳蹲移动、数字 1/2/3 轻拳/重拳/防御、回车大招；炸弹人玩家 2 使用方向键和回车。双人是同一台设备上的本地对战，三局两胜。经典、无限、双人最高分各自保存，格斗角色选择也会保留。

大乱斗与幸存者使用新增的 48 帧透明角色图集，覆盖呼吸、跑步、冲刺、大笑、轻拳、重击、受击与格挡。动作随游戏时钟播放，起手、发力和收招对应攻击阶段，转向及切换带短暂过渡；暂停、命中停顿与升级选择时按对应游戏状态冻结。笑声按出招、受伤、格挡、冲刺、连击、必杀、首领、升级和胜利等事件播放不同片段，具有冷却与优先级，始终最多一个笑声声源，声音开关可立即停止。

生成提示词和原始 PNG 见 [output/imagegen/prompts.md](output/imagegen/prompts.md)。可用 `node scripts/prepare-frog-frames.mjs output/imagegen/naiwa-motion-v1.png output/imagegen/naiwa-combat-v1.png` 重新生成 WebP 和脚底锚点。

## 本地运行

纯 HTML、CSS、原生 JavaScript 和 Canvas 2D，无前端运行时依赖或后端服务。所有游戏素材均随仓库保存。

```sh
python3 -m http.server 8080
```

访问 <http://localhost:8080>。请通过 HTTP 打开，以便浏览器加载 ES 模块及音频。

## 验证与构建

```sh
npm ci
npm test
npm run test:browser
npm run build
```

浏览器测试使用 Playwright Chromium。新环境先执行 `npx playwright install chromium`；也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定现有 Chromium 路径。测试覆盖电脑与手机输入、游戏切换、胜负计分、暂停、重开和本地存储。构建结果在 `dist/`，只包含公开网页及游戏素材。

可以在部署后对实际地址运行浏览器验收：

```sh
NAIWA_TEST_URL=https://sdjasj.github.io/naiwa-arcade/ npm run test:browser
```

测试使用独立浏览器上下文，存档与成绩不影响玩家。逻辑测试通过真实公开输入验证全部 12 个弹弓关卡、30 个跳跃平台和 8 波接蛙挑战可完成；2048 测试覆盖四方向合并、无效移动、终盘、撤销及中途刷新。新增测试验证格斗六擂与双人胜负、炸弹迷宫连通与六关通关、幸存者完整首领战及长时间数量上限；浏览器覆盖双人键盘、手机多点触控、升级选择与暂停释放。

## GitHub Pages

源代码位于 `main` 分支，网站构建产物位于 `gh-pages` 分支。GitHub Pages 的发布源设置为 `gh-pages` 的根目录。部署后的访问路径为 `/naiwa-arcade/`，资源路径均为相对路径，无需修改域名配置。

更新时运行构建，将 `dist/` 的内容发布到 `gh-pages` 并推送。无需令牌写入源代码、网页或构建产物。

## 结构

```text

styles.css              自适应布局

js/frog-animation.js    动作帧采样与循环 / 单次动作时序
js/frog-atlas.js        48 帧裁切边界与脚底锚点
js/audio.js             本地笑声与交互音效
js/games/               九款游戏的独立逻辑与渲染
assets/                 本地图集、音频及来源说明
tests/                  逻辑与浏览器验收测试
scripts/build.mjs       静态发布目录生成
output/imagegen/        生成帧源 PNG 与提示词（不发布到站点）
```

## 素材来源

奶蛙动画与笑声来自 [NaiLoong / linalg](https://github.com/lin-alg/NaiLoong)（[奶-hub](https://nai-hub.com/)）。完整来源与授权说明见 [assets/ATTRIBUTION.md](assets/ATTRIBUTION.md)。页面也保留来源链接。游戏为非商业同人作品；未使用经典游戏原版图片、角色、关卡或音频。
